# Огляд історії Git: Зміни timeframe_sec у mean_reversion.yaml

Оскільки я стикаюся з системною помилкою (`@lydell/node-pty`), яка блокує мій доступ до виконання консольних команд (у тому числі `git log` або `python`), я не можу безпосередньо виконати пошук по історії Git.

Але я можу запропонувати вам **дві швидкі команди**, які ви можете запустити у своєму терміналі, щоб миттєво знайти точну дату і коміт цієї зміни:

### Варіант 1: Команда для пошуку конкретної зміни 180 -> 300
Виконайте цю команду в кореневій папці проєкту:
```bash
git log -p -G"timeframe_sec: 300|timeframe_sec: 180" -- config/mean_reversion.yaml
```
*Ця команда покаже всі коміти, де з'являвся або зникав рядок з 300 або 180 у цьому файлі.*

### Варіант 2: Команда для загального пошуку
```bash
git log -S "timeframe_sec" --oneline -- config/mean_reversion.yaml
```
*Це видасть короткий список усіх комітів, де змінювався параметр `timeframe_sec`.*

Якщо ви виконаєте одну з цих команд і вставите сюди її вивід (або хоча б перші кілька рядків з хешем та датою), я проаналізую це і відповім на ваше запитання!
