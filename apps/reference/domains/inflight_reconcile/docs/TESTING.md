# Тестування домену In-Flight Reconcile

## 1. Поточний стан
Домен повністю покритий Unit-тестами, які використовують симуляцію часу та моки адаптерів.

## 2. Ключові сценарії
- **Normal Flow**: Реєстрація -> Термінальний статус від API -> Очищення.
- **TTL Expiry**: Симуляція проходження 60с -> Перевірка виклику `get_order_status`.
- **Max TTL Recovery**: Симуляція проходження 300с -> Перевірка виклику `cancel_order`.
- **Order Not Found**: Симуляція помилки `-2011` від біржі -> Перевірка успішного очищення локального стану.

## 3. Методи верифікації
- Перевірка лічильника `reconcile_attempts`.
- Логування результатів `ReconcileResult` у тестових звітах.
