# Архітектура домену Risk Management

## 1. Двохрівнева модель захисту
Система перевіряє ризики на двох рівнях:
1. **Портфельний рівень (Circuit Breaker)**: `DailyRiskState` відстежує просадку від капіталу на момент відкриття дня. Якщо ліміт перевищено, торгівля блокується для всіх символів.
2. **Інструментальний рівень**: `RiskScoreEngine` аналізує конкретний символ (волатильність, спред, стакан). Якщо `risk_score` перевищує поріг, блокується торгівля лише по цьому символу.

## 2. Персистентність денного стану (Daily Gate A3)
Стан денної просадки зберігається у файлі `data/risk_gate_state.json`. Це дозволяє системі "пам'ятати" про збитки навіть після перезавантаження процесу, запобігаючи випадковому розблокуванню торгівлі.

## 3. Принцип Fail-Closed (Безпека понад усе)
- Якщо дані про капітал відсутні або застарілі — торгівля **блокується**.
- Якщо конфігурація ризик-ваг некоректна — система **зупиняється** на старті.
- Будь-який внутрішній збій у розрахунку ризику призводить до вердикту `is_trading_allowed: False`.

## 4. Гнучкість для розробки (TASK47)
Домен підтримує прапор `disable_daily_loss_limit` виключно для режимів DEV/SHADOW. У цьому разі система емітує попередження, але дозволяє торгівлю навіть при перевищенні лімітів (для тестування стратегій).
