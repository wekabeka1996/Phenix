# Тестування домену Market Data

## 1. Стратегія тестування
Тестування зосереджене на перевірці цілісності агрегації барів та надійності IPC-з'єднання.

## 2. Ключові тестові набори
- **Bar Integration Tests**: Подача послідовності тіків з гепами та перевірка емісії `EVT:BAR_CLOSED`.
- **WSA Unit Tests**: Перевірка правильності розрахунку OBI/TFI на батчах угод.
- **IPC Stress Tests**: Перевірка пропускної здатності черги між процесами при інтенсивному потоці даних.

## 3. Сценарії верифікації
- **Order Preservation**: Перевірка, що OHLC дані відповідають вхідним тікам.
- **Graceful Reconnect**: Симуляція розриву WebSocket та перевірка автоматичного відновлення підписки.
- **Macro Sync**: Перевірка трансляції ціни BTC як якоря для інших символів.

## 4. Прогалини (Gaps)
- Відсутні "тортурні тести" (Torture Tests) на витік пам'яті під великим навантаженням.
- Недостатньо перевірок поведінки при екстремально великих розривах (Gaps) у ринкових даних (напр. година без тіків).
