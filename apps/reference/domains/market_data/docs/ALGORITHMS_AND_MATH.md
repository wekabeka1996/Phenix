# Алгоритми та математика Market Data

## 1. Агрегація веб-сокета (WSA)
Воркер не просто пересилає тіки, а виконує проміжну агрегацію:
- **Quote Updates**: Зберігає лише найсвіжіший `bookTicker` для кожного символу.
- **Trade Stream**: Накопичує суму `aggTrade` за період опитування (`poll_interval_sec`).

## 2. Розрахунок OBI/TFI всередині WSA
Для зменшення навантаження на `feature_engineering`, базові мікроструктурні ознаки рахуються прямо у воркері:
- $OBI = \frac{BidSize - AskSize}{BidSize + AskSize}$
- $TFI = \frac{\sum BuyVol - \sum SellVol}{\sum TotalVol}$

## 3. Алгоритм Bar Resampling
Ресамплер використовує детерміновану сітку часу:
$$BarStartTime = TS - (TS \pmod{TF_{sec} \cdot 1000})$$
Це забезпечує вирівнювання бару по круглих хвилинах/годинах незалежно від часу запуску системи.

## 4. Обробка запізнілих тіків (Out-of-Order)
Поточна реалізація `BarAggregator` використовує суворе відкидання:
- Якщо $TS_{new} \le TS_{last}$, тік ігнорується.
*Ризик: Це може призвести до втрати High/Low екстремумів при мережевому джитері.*
