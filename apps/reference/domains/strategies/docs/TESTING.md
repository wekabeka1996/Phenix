# Тестування домену Strategies

## 1. Стратегія тестування
Тестування зосереджене на правильності бутстрапу та валідації реєстру.

## 2. Ключові тестові набори
- **Registry Tests**: Перевірка реєстрації плагінів, детекція дублікатів ID.
- **Runtime Success**: Симуляція конфігу з призначеними ID та перевірка виклику методів `create_handler` та `register`.
- **Missing Plugin Recovery**: Перевірка, що відсутність плагіна для призначеного символу викликає правильну `ConfigContractError`.
- **Empty Config Handling**: Перевірка поведінки при відсутності призначень (система має стартувати, але нічого не запускати).

## 3. Методи верифікації
- Моки (`Mock`) об'єктів `FSMCore` та `StrategyPlugin` для відстеження викликів.
- Перевірка логів на наявність повідомлень про успішний старт стратегій.
