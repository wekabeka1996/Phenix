# Домен Strategies

## 1. Опис
Цей домен є менеджером рантайму для всіх торгових логік. Він забезпечує динамічне підключення стратегій до системи, гарантуючи відповідність між конфігурацією та реальним кодом.

## 2. Навігація по документації
- [**ATLAS.md**](./ATLAS.md) — Карта домену: реєстр, плагіни та залежності. **Головна точка входу.**
- [**ARCHITECTURE.md**](./ARCHITECTURE.md) — Внутрішня будова: протоколи та процес бутстрапу.
- [**EVENT_CONTRACTS.md**](./EVENT_CONTRACTS.md) — Специфікація протоколів `StrategyPlugin` та `StrategyHandler`.
- [**ALGORITHMS_AND_MATH.md**](./ALGORITHMS_AND_MATH.md) — Логіка збору та валідації призначених ID.
- [**QUALITY_AND_DEBT.md**](./QUALITY_AND_DEBT.md) — Аналіз технічного боргу та планів масштабування.
- [**TESTING.md**](./TESTING.md) — Сценарії тестування рантайму.

## 3. Як додати нову стратегію
1. Створіть файл плагіна у `plugins/`.
2. Реалізуйте протокол `StrategyPlugin`.
3. Зареєструйте його в `StrategyPluginRegistry` при ініціалізації системи.
