# Контракти домену Strategies

## Протоколи взаємодії

### `StrategyPlugin` (Factory)
Кожен плагін має надати:
- `strategy_id`: Унікальний рядок (напр. "aurora").
- `create_handler(fsm, config)`: Метод створення екземпляру логіки.

### `StrategyHandler` (Lifecycle)
Кожен обробник має реалізувати:
- `register()`: Метод, у якому об'єкт має викликати `fsm.listen()` для всіх подій, що йому необхідні для прийняття рішень.

## Механізм реєстрації
1. `registry.register(my_plugin)` — додавання до реєстру.
2. `runtime.start()` — автоматичне розгортання на основі конфігурації.
