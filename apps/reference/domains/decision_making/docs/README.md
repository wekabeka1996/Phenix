# Домен Decision Making

## 1. Опис
Цей домен є центральним інтелектуальним вузлом системи. Він приймає вхідні сигнали та перетворює їх на безпечні, зважені на ризик торгові наміри (intents).

## 2. Навігація по документації
- [**ATLAS.md**](./ATLAS.md) — Головна карта домену: межі, залежності, файли та події. **Почніть звідси.**
- [**ARCHITECTURE.md**](./ARCHITECTURE.md) — Внутрішня будова: фасад, гейти та оркестрація переворотів.
- [**EVENT_CONTRACTS.md**](./EVENT_CONTRACTS.md) — Детальні схеми подій та контрактів.
- [**ALGORITHMS_AND_MATH.md**](./ALGORITHMS_AND_MATH.md) — Математика скорингу, сайзингу та планування входу.
- [**QUALITY_AND_DEBT.md**](./QUALITY_AND_DEBT.md) — Аналіз технічного боргу, ризиків та захардкоджених параметрів.
- [**TESTING.md**](./TESTING.md) — Стратегія та сценарії тестування.

## 3. Розробка
При зміні логіки стратегії Aurora, редагуйте `aurora_scoring_kernel.py` (математика) або `aurora_handler.py` (керування станом).
