# Тестування домену Regime Allowlist

## 1. Стратегія тестування
Домен тестується через валідацію синтетичних словників конфігурації, симулюючи різні помилки розробника.

## 2. Ключові сценарії
- **Valid Config**: Перевірка, що правильна конфігурація (MR + FLAT) не викликає помилок.
- **MR Without Flat**: Перевірка виявлення критичного порушення, коли Mean Reversion включена лише для трендових режимів.
- **Empty Allowlist**: Перевірка, що порожній список призводить до блокування всіх режимів.
- **Unknown Regime**: Перевірка емісії попередження (WARNING) при друкарських помилках у назві режиму.

## 3. Методи верифікації
- Перевірка типу виключення `RegimeAllowlistError`.
- Перевірка текстового повідомлення в `violations` на відповідність очікуваному поясненню.
