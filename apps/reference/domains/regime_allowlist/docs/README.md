# Домен Regime Allowlist

## 1. Опис
Цей домен забезпечує логічну валідацію торгових стратегій відносно фаз ринку. Він гарантує, що кожна стратегія має принаймні один сумісний режим для роботи, та надає прозорі пояснення у разі блокування.

## 2. Навігація по документації
- [**ATLAS.md**](./ATLAS.md) — Карта домену: валідація, залежності та логіка старту.
- [**ARCHITECTURE.md**](./ARCHITECTURE.md) — Політика Fail-closed та матриця сумісності.
- [**EVENT_CONTRACTS.md**](./EVENT_CONTRACTS.md) — Реєстр відомих системі режимів.
- [**ALGORITHMS_AND_MATH.md**](./ALGORITHMS_AND_MATH.md) — Алгоритм розрахунку перетину множин режимів.
- [**QUALITY_AND_DEBT.md**](./QUALITY_AND_DEBT.md) — Аналіз ризиків розсинхронізації конфігурації.
- [**TESTING.md**](./TESTING.md) — Сценарії тестування логічних порушень.

## 3. Використання
Домен використовується як частина "Warmup" циклу системи:
```python
validate_strategy_regime_config(strategies_yaml, aurora_assets_yaml)
```
