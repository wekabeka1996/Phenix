# Алгоритми та математика Regime Allowlist

## 1. Алгоритм перевірки сумісності
Для кожного символу $S$ та стратегії $St$:
1. Визначити набір сумісних режимів $R_{compat}$ для типу $St$.
2. Отримати список дозволених режимів $R_{allowed}$ з конфігурації.
3. Розрахувати перетин: $I = R_{compat} \cap R_{allowed}$.
4. Якщо $I = \emptyset$ (порожня множина) та стратегія $St$ активна $	o$ **CRITICAL VIOLATION**.

## 2. Логіка виявлення невідомих режимів
Проста перевірка на входження елементів списку $R_{allowed}$ до глобального множини всіх відомих системі режимів $ALL\_REGIMES$. Будь-який елемент поза цією множиною викликає **WARNING**.

## 3. Обробка відсутності конфігурації
Застосовується принцип домінування порожньої множини:
- If $allowed\_regimes$ is $None 	o$ $R_{allowed} = \emptyset$.
- $\emptyset \cap R_{compat} = \emptyset 	o$ Block all.
