# Тестування домену Feature Engineering

## 1. Стратегія тестування
Тестування базується на детермінованих наборах тіків (snapshots) та перевірці математичної стабільності.

## 2. Ключові тестові набори
- **Snapshot Tests**: Порівняння розрахованих ознак з еталонними значеннями для фіксованого потоку тіків. Гарантує відсутність регресій при рефакторингу.
- **Warmup Tests**: Перевірка логіки `full_ready`. Ознаки не мають емітуватися, поки не накопичено достатньо даних (напр. для EMA з періодом 100).
- **Precision Tests**: Перевірка точності `Decimal` при глибоких математичних розрахунках волатильності.

## 3. Сценарії верифікації
- **Gap Handling**: Симуляція пропущених тіків — перевірка коректності роботи ресамплера.
- **Outlier Robustness**: Перевірка, що аномальна ціна (spike) коректно очищується через Winsorization.
- **Hot/Cold Sync**: Перевірка узгодженості даних Funding Rate з початком нового бару.

## 4. Прогалини (Gaps)
- Недостатньо тестів на продуктивність (latency benchmarks) при великій кількості активованих символів (100+).
- Відсутні автоматизовані тести на дрейф часу (clock skew) між ринковими даними та системним годинником.
