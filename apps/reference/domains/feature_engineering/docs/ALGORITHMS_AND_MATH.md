# Алгоритми та математика Feature Engineering

## 1. OBI (Order Book Imbalance)
Вимірює тиск покупців та продавців на вершині стакану.
$$OBI = \frac{BidSize - AskSize}{BidSize + AskSize}$$
Діапазон: $[-1, 1]$. $+1$ — сильний тиск покупців.

## 2. TFI (Trade Flow Imbalance)
Вимірює агресивність ринкових ордерів за період.
$$TFI = \frac{BuyVolume - SellVolume}{BuyVolume + SellVolume}$$

## 3. EMA Bias (Трендове відхилення)
Нормалізоване відношення швидкої EMA до повільної.
$$Bias_{raw} = \frac{EMA_{short} - EMA_{long}}{EMA_{long}}$$
Фінальне значення масштабується до діапазону $[0, 1]$ через `clamping` (зазвичай $\pm 2\%$).

## 4. Алгоритм Уелфорда (Online Variance)
Використовується для розрахунку волатильності без зберігання всієї історії тіків.
На кожному кроці оновлюються $M_n$ (середнє) та $S_n$ (сума квадратів відхилень):
$$M_n = M_{n-1} + \frac{x_n - M_{n-1}}{n}$$
$$S_n = S_{n-1} + (x_n - M_{n-1})(x_n - M_n)$$
Дисперсія: $\sigma^2 = \frac{S_n}{n-1}$.

## 5. Winsorization (Очищення викидів)
Для запобігання "вибухам" значень через аномальні тіки, всі ознаки проходять через гільйотину (clamping) на рівнях 1-го та 99-го перцентилів.
