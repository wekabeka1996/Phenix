# Алгоритми та математика Exchange Filters

## 1. Алгоритм порівняння (Filter Matching)
Домен виконує поетапну перевірку ключових числових параметрів.

**Критерії критичності (Criticality Logic):**
- **`step_size`**: Якщо `SSOT < Exchange`, це **CRITICAL**. Ми можемо надіслати кількість з завеликою точністю, яку біржа відхилить.
- **`min_qty`**: Якщо `SSOT < Exchange`, це **CRITICAL**. Ми можемо надіслати замалий ордер.
- **`min_notional`**: Якщо `SSOT < Exchange`, це **CRITICAL**. Ордер буде відхилений через малий загальний об'єм.

**Математична модель:**
Використовується тип `decimal.Decimal` для точного порівняння до останнього знака.

## 2. Парсинг RAW-даних біржі
Оскільки Binance API повертає фільтри у вигляді списку об'єктів з різними ключами (`stepSize` vs `minNotional`), домен реалізує нормалізацію:
- Конвертація рядків `"0.001"` у `Decimal("0.001")`.
- Об'єднання різних фільтрів (`LOT_SIZE`, `PRICE_FILTER`, `MIN_NOTIONAL`) у єдину структуру `ExchangeFilters`.

## 3. Рекомендація фіксу (Auto-Fix Suggestion)
При виявленні помилки, домен автоматично формує YAML-фрагмент, який розробник може скопіювати в `instruments.yaml` для виправлення конфігурації.
