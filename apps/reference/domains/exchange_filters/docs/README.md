# Домен Exchange Filters

## 1. Опис
Цей домен забезпечує відповідність внутрішньої конфігурації інструментів реальним обмеженням біржі. Він запобігає відхиленню ордерів через помилки в `instruments.yaml`.

## 2. Навігація по документації
- [**ATLAS.md**](./ATLAS.md) — Огляд домену, карта файлів та діаграма стартової валідації.
- [**ARCHITECTURE.md**](./ARCHITECTURE.md) — Деталі стратегії Fail-closed та пакетної обробки даних.
- [**ALGORITHMS_AND_MATH.md**](./ALGORITHMS_AND_MATH.md) — Логіка порівняння фільтрів та визначення критичності розбіжностей.
- [**QUALITY_AND_DEBT.md**](./QUALITY_AND_DEBT.md) — Аналіз технічного боргу та мережевих ризиків.
- [**TESTING.md**](./TESTING.md) — Сценарії тестування валідатора.

## 3. Використання
Домен викликається автоматично під час ініціалізації системи:
```python
await validate_instruments_on_startup(adapter, config, mode="live")
```
