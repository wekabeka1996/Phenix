# Тестування домену Exchange Filters

## 1. Поточний стан
Домен легко тестується через моки (mocks), оскільки його основна логіка — це чисте порівняння значень `Decimal`.

## 2. Ключові сценарії
- **Mismatch Detection**: Перевірка, що розбіжність у `min_notional` викликає правильний `FilterMismatch` з рівнем `CRITICAL`.
- **Severity Logic**: Перевірка, що `SSOT > Exchange` (суворіший ліміт) класифікується як `WARNING`, а не `CRITICAL`.
- **Fail-Fast**: Перевірка зупинки валідації на першій же помилці при `fail_fast=True`.
- **Empty SSOT**: Перевірка коректної обробки ситуації, коли в конфігу немає інструментів.

## 3. Методи верифікації
- Порівняння знімка `testnet_exchangeinfo.json` з результатами роботи валідатора в тестах.
- Перевірка повідомлення про помилку (`_format_message`) на наявність правильних рекомендацій для фіксу.
