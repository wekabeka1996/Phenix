# Тестування домену Execution Position

## 1. Стратегія тестування
Через критичну важливість домену, тестування зосереджене на гарантіях безпеки та відновленні після помилок.

## 2. Ключові тестові набори
- **FSM State Tests**: Перевірка переходів станів (Open -> Manage -> Close) за різних умов (Full Fill, Partial Fill, Cancel).
- **Guard & Clipping Tests**: Перевірка коректності зменшення об'єму ордера при наближенні до лімітів маржі.
- **Fail-Closed Tests**: Симуляція відсутності ціни або лімітів (відмова адаптера) — перевірка, що ордери НЕ відправляються.
- **Bootstrapping Tests**: Перевірка синхронізації плеча при старті з уже відкритою позицією на біржі.

## 3. Сценарії верифікації
- **Anti-2021**: Спроба поставити SL вище Mark Price (для Long) — перевірка автоматичного коригування.
- **Watchdog Timeout**: Мок затримки відповіді біржі — перевірка, що Watchdog ініціює скасування за TTL.
- **Supersede Flow**: Отримання нового сигналу OPEN під час відміни старого — перевірка черговості та відсутності дублів.

## 4. Метрики якості
- **Unit Coverage**: 90%+
- **Idempotency**: 100% (відсутність дублів ордерів у тестах).
- **Latency**: p95 < 20ms для внутрішньої логіки гейтів.
