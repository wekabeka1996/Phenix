# Домен Data Recorder

## 1. Опис
Цей домен забезпечує запис уніфікованих ринкових даних у CSV-файли для подальшого аналізу та бектестування.

## 2. Навігація по документації
- [**ATLAS.md**](./ATLAS.md) — Огляд домену, залежності та карта подій.
- [**ARCHITECTURE.md**](./ARCHITECTURE.md) — Логіка синхронізації (Joiner) та фонова обробка.
- [**EVENT_CONTRACTS.md**](./EVENT_CONTRACTS.md) — Опис вхідних контрактів.
- [**ALGORITHMS_AND_MATH.md**](./ALGORITHMS_AND_MATH.md) — Алгоритм часового об'єднання та форматування.
- [**QUALITY_AND_DEBT.md**](./QUALITY_AND_DEBT.md) — Аналіз технічного боргу та ризиків (Schema Drift).
- [**TESTING.md**](./TESTING.md) — Стратегія тестування синхронізації.

## 3. Використання
Рекордер запускається як сервіс, що слухає шину FSM.
Файли зберігаються за шляхом: `data/recorder/{date}/{symbol}_{tf}.csv`
