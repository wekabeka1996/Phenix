# Тестування домену Data Recorder

## 1. Поточний стан
Домен потребує тестів на коректність синхронізації (join) при затримках подій.

## 2. Сценарії для тестування
- **Happy Path**: Подія ознак -> подія режиму -> запис у CSV з усіма полями.
- **Regime Delay**: Ознаки прийшли, режим затримався на 1.5с -> перевірка, що рекордер дочекався і записав повний рядок.
- **Regime Timeout**: Режим не прийшов зовсім -> перевірка запису через 2с з `regime="PENDING"`.
- **Orphan Regime**: Режим прийшов раніше ознак -> перевірка коректної обробки (наразі може ігноруватися).

## 3. Методи верифікації
- Перевірка існування файлів у `data/recorder/`.
- Перевірка цілісності колонок CSV через `pandas.read_csv()`.
