# Алгоритми та математика Data Recorder

## 1. Алгоритм об'єднання (Temporal Join)
Рекордер реалізує алгоритм "Best-effort Join" за часовим штампом.

1. При отриманні `Features(ts)`:
   - Створити запис у буфері.
   - Помітити `recv_time = now`.
2. При отриманні `Regime(ts)`:
   - Знайти в буфері запис з таким самим `ts` та `symbol`.
   - Додати дані режиму до запису.
3. При виконанні `Flush`:
   - Якщо `now - recv_time > retention_sec`:
     - Записати рядок.
     - Якщо `Regime` відсутній — використати дефолтні значення.

## 2. Форматування даних
- **Timestamps**: Unix ms (integer).
- **ISO Date**: Конвертація `ts / 1000.0` у рядок ISO 8601 для зручності аналізу людиною.
- **Rounding**: Рекордер не округлює значення, записуючи їх як `str(val)`, що зберігає точність `Decimal`.
