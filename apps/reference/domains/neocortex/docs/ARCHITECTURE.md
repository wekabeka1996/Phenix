# Архітектура домену Neocortex

## 1. Процесна ізоляція
Домен запускається як **окремий процес операційної системи**. Це гарантує, що інтенсивні обчислення нейронних мереж або обробка великих масивів даних не блокують головний торговий потік (GIL isolation).

## 2. Пайплайн інгесту (Ingestion)
Neocortex поєднує два канали сприйняття:
- **Unified WAL Tailing**: Читання журналів транзакцій системи в реальному часі. Це забезпечує 100% каузальність (причинно-наслідковий зв'язок).
- **State Stream**: Пряме споживання ознак через FSM для побудови щільної моделі світу.

## 3. Brain Bridge (Багатопроцесні воркери)
Для паралельного виконання моделей використовується `BrainBridge` — пул воркерів, які обробляють епізоди пам'яті незалежно від основного циклу інгесту.

## 4. Епізодична пам'ять (Memory Buffer)
Домен реалізує `EpisodicBuffer` для зберігання траєкторій "спостереження -> дія -> нагорода". Це дозволяє системі навчатися на основі історичного досвіду (Replay).

## 5. Фазовий розвиток (Phased Maturity)
Архітектура підтримує поступове "дорослішання":
- **Phase 0 (Observer)**: Тільки спостереження та алертинг.
- **Phase 1 (Learner)**: Навчання прогнозуванню (World Model).
- **Phase 2 (Advisor)**: Генерація тіньових рекомендацій.
