# Тестування домену Snapshot Scheduler

## 1. Стратегія тестування
Тестування зосереджене на перевірці надійності циклу та коректності взаємодії з реєстрами доменів.

## 2. Ключові тестові набори
- **Success Cycle**: Створення мок-домену з методом `get_snapshot` та перевірка появи JSON-файлу на диску.
- **Implementation Missing**: Перевірка, що домени без методу `get_snapshot` просто ігноруються без помилок.
- **IO Error Handling**: Симуляція відсутності прав на запис у папку та перевірка інкременту лічильника `failed_snapshots`.
- **Stop Signal**: Перевірка швидкої зупинки потоку при вимкненні системи (Graceful shutdown).

## 3. Методи верифікації
- Перевірка існування файлів за допомогою `os.path.exists`.
- Валідація JSON структури записаних знімків через `json.loads`.
