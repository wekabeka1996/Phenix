# Контракти домену Snapshot Scheduler

## Протокол Snapshot
Кожен домен, який хоче підтримувати автоматичне резервування, має реалізувати метод:

### `get_snapshot() -> dict`
**Вимоги:**
- Результат має бути JSON-серіалізованим словником.
- Має містити `state_hash` для перевірки цілісності.
- Має включати версію схеми (`version`).

## Статистика планувальника
Домен надає метод `get_stats()` для моніторингу:
- `snapshot_count`: Загальна кількість успішних знімків.
- `failed_snapshots`: Кількість відмов (напр. через помилки IO).
- `last_snapshot_time`: Час останньої успішної операції.
