# Домен Snapshot Scheduler

## 1. Опис
Цей домен забезпечує регулярне створення резервних копій стану системи. Він є частиною стратегії відновлення після збоїв, дозволяючи відновити торгівлю з останньої збереженої точки.

## 2. Навігація по документації
- [**ATLAS.md**](./ATLAS.md) — Карта домену: архівація, залежності та вхідні точки. **Головна точка входу.**
- [**ARCHITECTURE.md**](./ARCHITECTURE.md) — Внутрішня будова: планувальник, виявлення доменів та зберігання.
- [**EVENT_CONTRACTS.md**](./EVENT_CONTRACTS.md) — Специфікація протоколу `get_snapshot()`.
- [**ALGORITHMS_AND_MATH.md**](./ALGORITHMS_AND_MATH.md) — Логіка іменування файлів та обробки черги.
- [**QUALITY_AND_DEBT.md**](./QUALITY_AND_DEBT.md) — Аналіз технічного боргу (Retention Policy).
- [**TESTING.md**](./TESTING.md) — Стратегія тестування циклів резервування.

## 3. Налаштування
Знімки зберігаються за шляхом: `ops/snapshots/`
Інтервал налаштовується в `system.yaml` -> `ops.snapshots.interval_sec`.
