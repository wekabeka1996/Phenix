# Алгоритми та математика Snapshot Scheduler

## 1. Алгоритм черговості
Планувальник виконує знімки послідовно (Sequential execution) для набору доменів. Це зроблено для запобігання надмірному навантаженню на диск, яке могло б виникнути при паралельному записі великих файлів.

## 2. Формування імені файлу
Використовується шаблон з міткою часу UTC:
$$Filename = Domain + "\_" + Format(Now_{UTC}, "Ymd\_HMS") + ".json"$$

## 3. Обробка помилок
У разі помилки в одному домені (напр. таймстамп-колізія або помилка серіалізації), планувальник:
1. Логує `ERROR` з повним трейсбеком.
2. Інкрементує лічильник `failed_snapshots`.
3. Негайно переходить до наступного домену в списку (Graceful skip).
