# Тестування домену Account Balance

## 1. Поточний стан
Домен має стабільне покриття інтеграційними тестами, які перевіряють взаємодію з адаптером та емісію подій.

## 2. Ключові тести
**Файл:** `tests/integration/test_account_connector.py` (орієнтовний шлях)

- `test_account_connector_initialization`: Перевірка створення об'єкта та завантаження конфігу.
- `test_account_connector_polling_and_event_emission`: Мок адаптера -> перевірка виклику `fsm.emit` з правильним payload.
- `test_account_connector_error_handling`: Симуляція помилок мережі -> перевірка, що цикл не переривається.
- `test_account_connector_graceful_shutdown`: Перевірка зупинки потоку та закриття сесій.

## 3. Оцінка покриття (Estimation)
- **Логіка емісії**: 95% (покриті всі фільтри балансів та позицій).
- **Обробка помилок**: 70% (покриті базові `Exception`, але не специфічні коди помилок API).
- **Конфігурація**: 100% (валідація `trading_mode` та ключів).

## 4. Прогалини (Gaps)
- Відсутні тести на екстремальні значення (дуже великі баланси, мікро-позиції).
- Немає тестів на поведінку при зміні API ключів "на льоту" (hot reload).
