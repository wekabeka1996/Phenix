# Тестування домену Position Tracking

## 1. Стратегія тестування
Тестування базується на симуляції складних послідовностей угод та перевірці математичної цілісності балансу.

## 2. Ключові тестові набори
- **Core Positioning**: Відкриття LONG/SHORT, дозакупка, часткове та повне закриття.
- **P&L Accuracy**: Перевірка розрахунку прибутку з урахуванням комісій (fees) та перевороту позиції.
- **WAL Resilience**: Симуляція крашу після запису у WAL та перевірка відновлення стану.
- **Sync Logic**: Симуляція розбіжності між локальним станом та відповіддю API Binance.

## 3. Метрики якості
- **Unit Coverage**: 100% на математичні розрахунки PnL.
- **Pass Rate**: 43/43 тестів проходять успішно.
- **Precision**: Перевірка збереження точності `Decimal` при серіалізації/десеріалізації.

## 4. Прогалини (Gaps)
- Відсутні тести на екстремально довгі ланцюги угод (1000+), що можуть накопичувати похибку округлення.
- Немає тестів на поведінку при зміні базової валюти акаунту (напр. перехід з USDT на BUSD).
