# Тестування домену Regime Detector

## 1. Стратегія тестування
Тестування фокусується на детермінованих переходах між фазами ринку при зміні волатильності та тренду.

## 2. Ключові тестові набори
- **Regime Transition Tests**: Подача послідовності цін (uptrend -> sideways -> crash) та перевірка послідовності режимів.
- **Hysteresis Verification**: Перевірка затримки зміни режиму на рівні $N$ барів.
- **Data Quality Tests**: Симуляція застарілих таймстампів та перевірка скидання в `UNCERTAIN`.
- **Warmup Tests**: Перевірка, що режим не емітується (або емітується як UNCERTAIN) до накопичення достатньої довжини буфера SMA.

## 3. Методи верифікації
- Порівняння результатів `RegimeDetector` з еталонними розрахунками в Pandas.
- Перевірка логів `inc_data_quality_drop` на наявність правильних причин відмов.

## 4. Прогалини (Gaps)
- Недостатньо тестів на стійкість до "шумних" даних (високочастотні коливання навколо порогів).
- Відсутні тести на продуктивність при одночасному моніторингу 50+ символів.
