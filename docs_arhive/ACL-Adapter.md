# ACL Adapter � � Exchange Integration

## Overview

**ACL (Anti-Corruption Layer)** adapter provides clean integration between exchange events and internal FSM Message protocol. It operates in **shadow-mode** by default: receives events, generates decisions, but does NOT place live orders.

## Architecture

```
Exchange (stub) ←→ ACL Adapter ←→ Router ←→ FSM Domains
                      ↓
                   Metrics
                   Idempotency
                   Validation
```

## Interfaces

### ExchangeACL

Main adapter class with three key methods:

#### `submit(cmd: Message) -> Message`
Submit command to exchange (shadow stub).

**Input:** `Message` with `op=CMD`, `verb ∈ {OPEN, CLOSE, ADJUST}`

**Output:** `Message` with `op=EVT`, `verb=ORDER_PLACED` or `REJECTED`

**Validation:**
- Contract compliance (`op`, `verb`, `why≤80`)
- Idempotency check (deterministic key)
- Fail-closed: reject invalid contracts

#### `cancel(cmd: Message) -> Message`
Cancel existing order.

**Input:** `Message` with `verb=CLOSE`

**Output:** `Message` with `verb=CANCELLED`

#### `stream_events() -> Iterator[Message]`
Stream exchange events (stub generator).

**Yields:** `Message` with `op=EVT`, `verb ∈ {PARTIAL_FILL, FILL, CANCELLED, REJECTED, EXPIRED}`

## Domain Contracts

### Enums
- **Side:** `BUY`, `SELL`
- **OrderType:** `MARKET`, `LIMIT`, `STOP_LIMIT`
- **TimeInForce:** `GTC`, `IOC`, `FOK`
- **OrderStatus:** `PENDING`, `PLACED`, `PARTIAL`, `FILLED`, `CANCELLED`, `REJECTED`, `EXPIRED`

### Constraints
- `MIN_ORDER_QTY = 0.001`
- `MAX_ORDER_QTY = 1000.0`
- `MIN_PRICE = 0.01`
- `MAX_PRICE = 1000000.0`

## Metrics

Tracked via `get_acl_metrics()`:

- `events_rx_total`: Total events received from exchange
- `events_tx_total`: Total commands sent to exchange
- `rejects_total`: Invalid contract rejections
- `dedup_total`: Duplicate request deduplication
- `latency_p95_ms`: p95 latency for submit operations

## Shadow Mode

In shadow mode (default):
- All `submit()` calls return stub responses
- No real orders placed on exchange
- Events generated by stub for testing
- Full message flow preserved for FSM testing

## Integration Example

```python
from vfoundation.adapters.exchange import ExchangeACL
from vfoundation.core.protocol import Message

# Initialize ACL
acl = ExchangeACL(shadow_mode=True)

# Submit order command
cmd = Message(
    op="CMD",
    verb="OPEN",
    src="trader",
    dst="exchange",
    rid="trade-001",
    why="open long position",
    pld={
        "symbol": "BTCUSDT",
        "side": "BUY",
        "qty": 1.0,
        "price": 50000.0
    }
)

response = acl.submit(cmd)
print(f"Status: {response.verb}")  # ORDER_PLACED

# Stream events
for event in acl.stream_events():
    print(f"Event: {event.verb} - {event.pld}")
```

## Error Handling

ACL uses **fail-closed** pattern:
- Invalid `op` → `ERR:INVALID_OP`
- Invalid `verb` → `ERR:INVALID_VERB`
- Duplicate request → `EVT:DEDUP` (no WAL write)
- All errors respect `why≤80` discipline
