##                                   `visualizer.py`

                     Graphviz        Mermaid-                  :

```python
import json
from graphviz import Digraph

def visualize(log_file="shadow_logs.jsonl", out_file="fsm_chain.svg"):
    g = Digraph("ShadowFSM", format="svg")
    with open(log_file) as f:
        events = [json.loads(line) for line in f]
    last = None
    for e in events:
        evt = e["event"]
        g.node(evt, evt, shape="box")
        if last:
            g.edge(last, evt)
        last = evt
    g.render(out_file, view=False)
```
