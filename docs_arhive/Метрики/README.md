# Aurora/WiseScalp — План інтеграції нових метрик

Цей каталог містить результати дослідження та покроковий план впровадження нових метрик аналізу ринку в системі Aurora/WiseScalp.

Документи:
- METRICS_INTEGRATION_PLAN.md — повний технічний огляд, дорожня карта, тест-план, DoD, ризики/відкат.
- VALIDATION_CHECKLIST.md — чекліст ручної валідації після інтеграції.
- SYNTHETIC_DATASET_SPEC.md — специфікація синтетичного датасета для бектесту/регресії.
- CONFIG_SNIPPETS.yaml — рекомендовані зміни у конфігах (`config/aurora/trading.yaml` — джерело істини).
