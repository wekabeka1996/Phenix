## 🎯 БАЗОВІ ПОНЯТТЯ

### 1. BPS (Basis Points) - Одиниця Вимірювання

```
1 BPS = 0.01% = 1/100 від одного відсотка

Приклади:
  • 50 BPS = 0.5%
  • 100 BPS = 1%
  • 10000 BPS = 100%
```

### 2. Entry Price - Твоя Позиція

```
Де ти вийшов на ринок.
Приклад: 45,000 USDT для BTC або 3.5 USDT для ETH
```

### 3. Stop Loss (SL) - Рис

```
"Якщо ринок проти мене - виходи на максимальному збитку"

Формула (LONG):
  SL = Entry × (1 - SL_bps / 10000)

Приклад:
  Entry = 45,000
  SL = 50 BPS = 0.5%
  SL_Price = 45,000 × (1 - 0.005) = 44,775
```

### 4. Take Profit (TP) - Мета Прибутку

```
"Якщо ринок за мною - виходи на обраному прибутку"

Формула (LONG):
  TP = Entry + (SL_bps × ratio) × (Entry / 10000)

Приклад:
  Entry = 45,000
  SL = 50 BPS
  Ratio = 1.0
  TP = 45,000 + (50 × 1.0) × (4.5) = 45,225
```

## 🔧 ЯКИЙ ПАРАМЕТР ЗА ЩО ВІДПОВІДАЄ?

### Параметр 1: `stop_loss_bps`

```yaml
# config/aurora/trading.yaml, лінія 151
stop_loss_bps: 50
```

**Що він робить**:
- Визначає дистанцію SL від entry
- Прямо впливає на ризик кожної торгівлі

**Як змінювати**:

| Зміна | Ефект | Хто Користується |
|------|-------|-----------------|
| Більше (75→100) | Більше місця для коливань, більше ризик | Волатильні ринки |
| Менше (50→30) | Менше місця, менше ризик | Спокійні ринки |

---

### Параметр 2: `take_profit_low_ratio` (k₁)

```yaml
# config/aurora/trading.yaml, лінія 152
take_profit_low_ratio: 0.6
```

**Що він робить**:
- Визначає LOW TP (мінімальний прибуток)
- Формула: `TP_low = SL_bps × 0.6`

**Як змінювати**:

| Значення | TP від Entry | Характер |
|----------|-------------|----------|
| 0.4 | ~0.2% | Консервативно (швидкий хіт) |
| 0.6 | ~0.3% | **По замовчуванню** |
| 0.8 | ~0.4% | Агресивно (чекаємо більше) |
| 1.0 | ~0.5% | Дуже агресивно (максимум) |

---

### Параметр 3: `take_profit_high_ratio` (k₂)

```yaml
# config/aurora/trading.yaml, лінія 153
take_profit_high_ratio: 1.0
```

**Що він робить**:
- Визначає HIGH TP (максимальний прибуток)
- Формула: `TP_high = SL_bps × 1.0`

**Як змінювати**:

| Значення | TP від Entry | Характер |
|----------|-------------|----------|
| 0.8 | ~0.4% | Консервативно |
| 1.0 | ~0.5% | **По замовчуванню** |
| 1.25 | ~0.625% | Агресивно |
| 1.5 | ~0.75% | Дуже агресивно |

## 📊 ПРАКТИЧНІ ПРИКЛАДИ

### Приклад 1: Ринок Спокійний

**Ситуація**: BTC тренд вверх, слабка волатильність, хочу більше трейдів

**Рішення**:
```yaml
stop_loss_bps: 35          # Менше ризику
take_profit_low_ratio: 0.8 # Більш привабливий
take_profit_high_ratio: 1.3 # Дуже привабливий
```

**Результат** (Entry=45,000):
```
SL = 44,842.5 (-0.35%)
TP_low = 45,126 (+0.28%)
TP_high = 45,441 (+0.98%)
```

**Вплив**:
- ✅ Більше трейдів (TP ближче)
- ✅ Менше ризику (SL ближче)
- ❌ Менше прибутку за трейд

---

### Приклад 2: Ринок Волатильний

**Ситуація**: Різкі коливання, часто хітає SL, хочу більше місця

**Рішення**:
```yaml
stop_loss_bps: 75          # Більше місця для коливань
take_profit_low_ratio: 0.5 # Менш оптимістично
take_profit_high_ratio: 1.25 # Амбіційнісше
```

**Результат** (Entry=45,000):
```
SL = 44,662.5 (-0.75%)
TP_low = 45,168.75 (+0.375%)
TP_high = 45,421.875 (+0.9375%)
```

**Вплив**:
- ✅ Менше false-stops
- ✅ Більший потенціальний прибуток
- ❌ Менше трейдів

---

### Приклад 3: Агресивна Торгівля (Scalp)

**Ситуація**: Мікро-трейди, хочу максимум операцій на день

**Рішення**:
```yaml
stop_loss_bps: 20          # Мінімальний ризик
take_profit_low_ratio: 1.0 # Швидко TP
take_profit_high_ratio: 1.5 # Максимум можливого
```

**Результат** (Entry=45,000):
```
SL = 44,910 (-0.2%)
TP_low = 45,090 (+0.2%)
TP_high = 45,135 (+0.3%)
```

**Вплив**:
- ✅ Максимум трейдів (близкі TP)
- ✅ Мінімум ризику
- ❌ Малий прибуток за трейд
