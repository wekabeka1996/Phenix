# P2 recommendation

Do not start execution authority. The smallest evidence-led P2 is a runtime observation pass for this same read-only bridge:

1. Start the existing Aurora FastAPI host on its approved non-7102/non-8443 port.
2. Poll BTCUSDT and ETHUSDT through Cockpit for a bounded observation window.
3. Confirm snapshot runtime ownership, clock alignment, packet persistence, UI refresh, and rotation behavior.
4. Add authenticated transport only if the endpoint leaves loopback.
5. Define a dedicated bounded runtime execution-readiness snapshot so filter, precision, reduce-only, bracket, mode, and secret-isolation states can move from unknown without inspecting secrets.

AgentIntent, order routing, policy disabling, action-review ledgers, council, ranking, reputation, auto-loop, and provider arbitration remain out of scope.
