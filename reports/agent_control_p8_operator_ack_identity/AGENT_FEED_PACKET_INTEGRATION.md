# AgentFeedPacket integration

The compact per-symbol projection contains:

- symbol and parity status;
- acknowledgement and validation status;
- operator id when a parsed candidate exists;
- created and expiry timestamps;
- exact state ref;
- review-required flag;
- compact reason;
- provenance/raw/history refs.

The authored file and full validated record are not embedded. Ten runtime packets projected only BTCUSDT and ETHUSDT and stayed below 4,400 tokens without truncation.
