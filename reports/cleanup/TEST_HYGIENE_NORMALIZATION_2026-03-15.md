## 2. xfail Decision and Evidence

**File:** `tests/units/test_binance_adapter_session.py`

**Original marker:** `@pytest.mark.xfail(reason="Flaky: state leakage from other async tests in full suite", strict=False)`

**Why it was marked:** The reason string says "state leakage from other async tests in full suite" — the test was flaky when run alongside other async tests due to shared event loop state.

**Does it pass consistently now?** Yes. Tested both in isolation and as part of the Wave 2 batch run (where it showed XPASS). The underlying async framework issues have been resolved by the project's migration to `pytest-asyncio` strict mode.

**Decision:** **REMOVE xfail** — the marker is stale. The test has 3 real assertions testing session injection and request routing on `BinanceAdapter`. It passes reliably.

**Change:** Removed `@pytest.mark.xfail(...)` decorator, kept `@pytest.mark.asyncio`.
