# Scenario taxonomy

The exact P9 ids are:

- `continuation`
- `mean_reversion`
- `fakeout_reversal`
- `chop_fee_trap`
- `late_entry_failure`
- `breakout_followthrough`
- `volatility_expansion`
- `volatility_compression`
- `unexpected_news_or_external`
- `data_stale_or_missing`
- `no_clear_scenario`

Expected scenario ids must be unique, each carries confidence and evidence refs, and realized outcomes use the same enum. P9 deliberately does not add a broad ontology.
