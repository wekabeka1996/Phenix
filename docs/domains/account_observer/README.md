# Account Observer Domain (Домен Спостерігача Рахунку)

## Огляд

Домен `account_observer` є критичним компонентом системи Aurora, що забезпечує пасивний моніторинг торгової активності на Binance Futures. Він використовує read-only API ключі для періодичного опитування біржі та емісії подій про виконані торгові операції.

## Архітектурна роль

### Відповідальність
- **Моніторинг трейдів:** Пасивне спостереження за виконаними угодами через Binance API
- **Дедуплікація:** Відстеження оброблених трейдів для уникнення дублікатів подій
- **Стандартизація даних:** Перетворення сирих API даних в структуровані FSM події
- **Надійність:** Забезпечення системи актуальною інформацією про торгову активність

### Критичність для системи
Домен є фундаментальним для:
- **Position Tracking** - синхронізація стану позицій з реальними трейдами
- **Risk Management** - перерахунок ризиків після виконання операцій
- **Audit Trail** - запис всіх операцій для аудиту та аналізу

## Основні компоненти

### AccountObserver
Головний клас домену, що реалізує моніторинг трейдів через Binance API.

**Ключові можливості:**
- Автоматичний вибір API залежно від режиму роботи (live/testnet/hybrid)
- Фоновий моніторинг з конфігурованим інтервалом
- Дедуплікація трейдів за ID для уникнення дублікатів
- Структурована емісія FSM подій про виконані операції

## FSM події

### Генеровані події
- `EVT:TRADE_EXECUTED` - повідомлення про виконання нової торгової операції

### Споживані події
Домен працює автономно і не споживає зовнішні події.

## Взаємодії з доменами

### Синхронні зв'язки
- **Position Tracking** ← `EVT:TRADE_EXECUTED`
- **Risk Management** ← `EVT:TRADE_EXECUTED`
- **Audit Trail** ← `EVT:TRADE_EXECUTED`

### Асинхронні залежності
Домен працює незалежно, але його події критичні для всіх компонентів, що відстежують позиції.

## Конфігурація

### Основні параметри
```yaml
# Загальна конфігурація системи
trading_mode: "testnet"

# API конфігурація
binance_api:
  testnet:
    api_key: "${BINANCE_TESTNET_API_KEY}"
    api_secret: "${BINANCE_TESTNET_API_SECRET}"

# Конфігурація домену account_observer
account_observer:
  poll_interval: 5        # секунди між опитуваннями
  symbols:                # символи для моніторингу
    - BTCUSDT
    - ETHUSDT
    - BNBUSDT
  trade_limit: 50         # кількість трейдів за запит
```
  trade_limit: 50        # кількість трейдів для перевірки

## Моніторинг

### Метрики
- `account_observer.trades_processed` - Кількість оброблених трейдів
- `account_observer.new_trades_detected` - Кількість нових трейдів
- `account_observer.api_errors` - Кількість помилок API
- `account_observer.poll_interval_actual` - Фактичний інтервал опитування

### Логування
- INFO: Виявлення нових трейдів, емісія подій
- DEBUG: Деталі опитування кожного символу
- ERROR: Критичні помилки API або парсингу
