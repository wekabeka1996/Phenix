## Розрахунок індикаторів

### Order Book Imbalance (OBI)
```
OBI = (bid_size - ask_size) / (bid_size + ask_size)
```
**Діапазон:** [-1, 1]  
**Інтерпретація:** Позитивне значення вказує на більший bid volume, негативне - на більший ask volume.

### Trade Flow Imbalance (TFI)
```
TFI = (buy_volume - sell_volume) / (buy_volume + sell_volume)
```
**Діапазон:** [-1, 1]  
**Інтерпретація:** Позитивне значення вказує на переважання покупок, негативне - продажів.

### Delta Price
```
delta_price = current_price - previous_price
```
**Інтерпретація:** Зміна ціни між ticks. Обмежено 1000ms для уникнення великих � трибків.
