# Візуалізація латентного простору VAE

## Опис проекту

Цей набір скриптів призначений для генерації та візуалізації латентних векторів з навченої VAE моделі для аналізу часових рядів (AR, GARCH, ARMA-GARCH).

## Структура файлів

1. **generate_latent_vectors.py** - Генерація латентних векторів μ з енкодера VAE
2. **latent_space_visualization.py** - Візуалізація латентного простору за допомогою t-SNE та UMAP
3. **run_full_pipeline.py** - Автоматичний запуск повного пайплайну

## Вимоги

### Вхідні файли

1. **vae_model_weights.pth** - Ваги навченої VAE моделі (ОБОВ'ЯЗКОВО!)
2. **Z_train.npy** - θ-вектори тренувальних моделей (розмір: [n_samples, 40])
3. **train_labels.npy** - Мітки для тренувальних моделей ('AR' або 'GARCH')
4. **generated_valid_thetas.npy** - θ-вектори згенерованих ARMA-GARCH моделей (розмір: [965, 40])

## Важливі налаштування

### Архітектура VAE
```python
D_STRUCT = 10    # Дискретні структурні параметри
D_PARAM = 20     # Безперервні параметри
D_STAT = 10      # Статистичні характеристики
D_LATENT = 8     # Розмірність латентного простору
D_INPUT = 40     # Загальна розмірність входу (D_STRUCT + D_PARAM + D_STAT)
```

### Параметри візуалізації

**t-SNE:**
- perplexity = 30
- n_iter = 1000

**UMAP:**
- n_neighbors = 15
- min_dist = 0.1

## Інтерпретація результатів

Візуалізація показує:
- **Сині точки** - Тренувальні AR моделі
- **Червоні точки** - Тренувальні GARCH моделі
- **Зелені точки** - Згенеровані ARMA-GARCH моделі

Очікувані паттерни:
1. AR та GARCH моделі повинні формувати окремі кластери
2. ARMA-GARCH моделі можуть розташовуватися між або навколо цих кластерів
3. Щільність точок вказує на типовість моделей

## Налагодження

### Проблема: "Файл vae_model_weights.pth не знайдено"
**Рішення:** Переконайтеся, що ви зберегли ваги навченої моделі:
```python
torch.save(vae_model.state_dict(), 'vae_model_weights.pth')
```

### Проблема: "Розмірність даних не відповідає"
**Рішення:** Перевірте, що D_INPUT = 40 відповідає розмірності ваших θ-векторів

### Проблема: "UMAP не встановлено"
**Рішення:** 
```bash
pip install umap-learn
```
