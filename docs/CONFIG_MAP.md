## Schema vs YAML Reconciliation

### Loader Migrations / Structure Drift (By Design)

The loader performs explicit migrations before Pydantic validation:
- `system.yaml` root meta keys (e.g. `sequential_tests`, `risk_core`, `kelly`, …) are moved under `system_meta.*`.
- `regime.yaml:config_version` is moved to `system_meta.regime_config_version`.
- `regime.yaml:hotreload_whitelist` stays at root and is also copied into `system_meta.hotreload_whitelist`.
- `domains.yaml` is loaded under `domains.*` (entire file is namespaced).
- `strategies.yaml` is loaded under `strategies_registry.*`.
- `strategies/<id>.yaml` is loaded under `strategies.<id>.*` (with optional top-level `<id>` wrapper).
