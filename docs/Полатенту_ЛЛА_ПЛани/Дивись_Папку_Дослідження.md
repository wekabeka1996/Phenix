# GEOMETRIC SCHRÖDINGER BRIDGE: THEORETICAL FOUNDATION

**Module:** Research / GSB
**Status:** MVP / Proof-of-Concept
**References:** Arvanitidis et al. (2018), De Bortoli et al. (2021), O'Keefe (2014)

## 1. The Core Problem: The "ARMA-Barrier"
Traditional generative models for financial time series (VAEs, GANs) assume a flat Euclidean latent space ($g_{ij} = \delta_{ij}$). When interpolating linearly between a current state $z_t$ and a target state $z_{t+T}$, the path often traverses the center of the Gaussian manifold ($\mathcal{N}(0, I)$).

In financial terms, this center often represents "theoretical equilibrium" or "maximum uncertainty," regions which may correspond to:
1.  **Explosive Volatility:** The decoder maps $z \approx 0$ to unrealistic variance.
2.  **Liquidity Vacuum:** The state implies an order book structure that cannot exist physically.
3.  **Non-Stationarity:** Violation of econometric assumptions (e.g., GARCH $\alpha + \beta > 1$).

We term this phenomenon the **"ARMA-Barrier"**. Naive interpolation crashes through this barrier, yielding invalid scenarios.

## 2. The Solution: Riemannian Manifold Learning
We propose that the market evolves on a learned Riemannian manifold $\mathcal{M}$ where the metric tensor $g_\phi(z)$ defines the concept of "distance" based on stability, not Euclidean proximity.

### 2.1. The Metric Network
We approximate the metric tensor using a neural network to ensure it is Symmetric Positive Definite (SPD):
$$g_\phi(z) = D_\phi(z) + U_\phi(z) U_\phi(z)^\top + \epsilon I_d$$
where $D$ is diagonal and $U$ is low-rank.

### 2.2. The Adaptive Barrier Potential
We define a scalar potential field $V(z)$ representing "Risk Energy":
$$V(z) = w_1 \mathcal{L}_{\text{NLL}} + w_2 \mathcal{L}_{\text{Stationarity}} + w_3 \mathcal{L}_{\text{Tail}}$$
High $V(z)$ implies a dangerous or unrealistic market state.

## 3. Schrödinger Bridge Formulation
Instead of deterministic paths, we solve the Schrödinger Bridge Problem (SBP). We seek a path measure $\mathbb{P}$ connecting the initial distribution $\mu_0$ and target $\mu_T$ that minimizes the Kullback-Leibler divergence from a reference geometric process $\mathbb{Q}$:

$$\inf_{\mathbb{P} \in \Pi(\mu_0, \mu_T)} \text{KL}(\mathbb{P} || \mathbb{Q})$$

The reference process $\mathbb{Q}$ follows Langevin dynamics on the manifold:
$$dZ_t = -\frac{1}{2} g^{-1}(Z_t) \nabla V(Z_t) dt + \sqrt{g^{-1}(Z_t)} dW_t$$

Practically, this means the generated scenarios naturally "flow" around high-risk barriers ($V(z)$), following the valleys of the learned metric, mimicking the behavior of liquidity flows in real markets.

# CORE MODELS API REFERENCE

This document describes the neural components responsible for perception and geometry.

## 1. RobustVAE (`src/models/vae.py`)
A specialized Variational Autoencoder designed for financial microstructure features.

### Architecture
* **Input:** `[Batch, Seq_Len, Features]` (e.g., Returns, OBI, Volatility Kappa).
* **Encoder:** Bidirectional GRU $\to$ Linear Projection $\to$ $(\mu_z, \sigma_z)$.
* **Latent Space:** $z \in \mathbb{R}^{12}$ (Compressed regime representation).
* **Decoder:** Student-t Distribution Head. Outputs parameters $(\mu_r, \sigma_r, \nu_r)$ for the next return.

### Key Features
* **Heavy-Tail Awareness:** The learned degrees of freedom ($\nu$) allow the model to explicitly distinguish between "Gaussian Noise" (high $\nu$) and "Black Swan Events" (low $\nu$).
* **Loss Function:**
    ```python
    Loss = NLL_StudentT(target, pred) + beta * KL_Divergence(z, Normal(0,1))
    ```

## 2. MetricNetwork (`src/geometry/metric.py`)
A neural network that outputs the local Riemannian metric tensor at any point $z$.

### Architecture
* **Input:** Latent vector $z \in \mathbb{R}^{12}$.
* **Hidden Layers:** MLP with Softplus activations (to ensure smoothness).
* **Output Heads:**
    * `diag`: Diagonal elements of $D$ (positive).
    * `factors`: Low-rank factors $U$ (for curvature).

### Usage
```python
metric_net = MetricNetwork(input_dim=12, rank=3)
G, det_G = metric_net(z)
# G is [Batch, 12, 12] - The local "ruler" for distance

```

### Interpretation

* **High Volume ():** Indicates a region where "small latent change = massive market impact" (e.g., liquidity crisis).
* **Low Volume:** Indicates a region where the market can move freely without resistance (e.g., stable trend).

# SOLVER API: PARTICLE SINKHORN

This module implements the core generation logic using Discrete Optimal Transport.

## 1. ParticleSinkhornSolver (`src/dynamics/sinkhorn.py`)
Solves the entropy-regularized optimal transport problem to generate non-linear trajectories.

### Algorithm: Iterative Proportional Fitting (IPF)
Instead of solving a PDE, we discretize the probability mass into $N$ particles and iterate:
1.  **Forward Projection:** Adjust potentials to match the starting distribution (Current Market).
2.  **Backward Projection:** Adjust potentials to match the target distribution (Forecast).

### Key Parameters
* `epsilon` (Regularization): Controls the "fuzziness" of the bridge. Higher $\epsilon$ = closer to Brownian motion; Lower $\epsilon$ = closer to Geodesic (deterministic).
* `n_steps`: Number of time steps in the generated scenario (e.g., 24 hours).

## 2. Cost Function (`src/dynamics/kernels.py`)
The "Physical Cost" of moving from state $z_i$ to $z_j$.

$$C(z_i, z_j) = \underbrace{\frac{1}{2} \Delta z^\top g(z_{mid}) \Delta z}_{\text{Geodesic Energy}} + \underbrace{\lambda V(z_j)}_{\text{Barrier Penalty}} + \underbrace{\gamma \|v_j - v_i\|^2}_{\text{Momentum}}$$

* **Geodesic:** Penalizes moving through "stretched" space (crises).
* **Barrier:** Hard penalty for entering non-stationary zones.
* **Momentum:** Enforces smoothness (prices don't teleport without jumps).

## 3. Log-Domain Implementation
All Sinkhorn updates are performed in the Log-Domain (`LogSumExp`) to prevent numerical underflow when $\epsilon \to 0$.

# GSB OPERATIONAL MANUAL

**Objective:** Run the Geometric Schrödinger Bridge to generate risk-aware scenarios.

## 1. Installation
The GSB is a standalone research module. It does NOT require the full Neocortex/Aurora system to run in "Research Mode".

```bash
pip install torch geomloss numpy matplotlib pandas

```

*(Note: `geomloss` is required for efficient Sinkhorn kernels).*

## 2. The Pipeline

### Step 1: Feature Extraction (VAE)

Train the VAE on historical microstructure data to learn the latent map.

```bash
python scripts/train_vae.py --data data/market_features.jsonl --epochs 50

```

*Output:* `checkpoints/vae_microstructure.pth` and `data/latent_trajectory.pt`.

### Step 2: Geometry Learning

Train the Metric Network to learn the "Risk Landscape" ( and ).

```bash
python scripts/train_metric.py --latent data/latent_trajectory.pt

```

*Output:* `checkpoints/metric_net.pth`.

### Step 3: Target Generation (Predictor)

GSB needs a target distribution  (Where will the market be in 24h?).
We support two modes:

* **Mode A (Heuristic - Default):** Uses Momentum + Mean Reversion logic on the latent state. Robust and autonomous.
```python
predictor = HeuristicPredictor(lookback=24, mean_reversion_strength=0.1)

```


* **Mode B (World Model - Advanced):** Connects to `Neocortex.WorldModel` (GRU/Transformer).
* *Status:* Experimental. Requires trained World Model weights.



### Step 4: Scenario Generation (SBP)

Run the solver to generate paths.

```bash

python scripts/run_sbp.py --start_index -1 --horizon 24 --n_paths 100

```

## 3. Interpreting Results (Backtest)

Use `scripts/backtest_comparison.py` to validate economic value.

* **Naive GBM:** Simulates Random Walk. Often underestimates tail risk.
* **SBP-based:** Simulates Geometric Flows.
* **Success Metric:** If SBP scenarios allow a CVaR optimizer to avoid drawdowns that Naive scenarios missed, the model adds Alpha.



## 4. Known Limitations (MVP)

1. **Computation:** The Sinkhorn solver is . For >2048 particles, GPU is required.
2. **Target Uncertainty:** The quality of the bridge depends on the quality of the Target Predictor. GSB builds the *best path*, but relies on the Predictor for the *destination*.
