# OPERATIONAL MANUAL & DEPLOYMENT
**Project:** Aurora / Neocortex
**Target Audience:** DevOps / Algo-Traders

## 1. Setup & Installation

### 1.1. Prerequisites
*   **OS:** Linux (Ubuntu 22.04+ recommended) / Windows (via WSL2).
*   **Python:** 3.10+ (Strict Requirement).
*   **Hardware:** 16GB+ RAM, NVIDIA GPU (Optional but recommended for PyTorch).

### 1.2. Environment Setup
1.  **Clone Repository:**
    ```bash
    git clone <repo_url>
    cd aurora-system
    ```
2.  **Create Virtual Environment:**
    ```bash
    python -m venv venv
    source venv/bin/activate  # Linux
    .\venv\Scripts\activate   # Windows
    ```
3.  **Install Dependencies:**
    ```bash
    pip install -r requirements.txt
    ```
    *Ensure `torch` is installed with CUDA support if GPU is available.*

4.  **Environment Variables (`.env`):**
    Create a `.env` file in the root:
    ```ini
    PYTHONPATH=.
    LLA_LOG_LEVEL=INFO
    LLA_MODE=SHADOW
    ```

## 2. Running Experiments

### 2.1. Validating Configuration
Before running, validate that all configs are strictly compliant with the schema:
```bash
python -m vfoundation.cli.vfound config validate
```

### 2.2. Running Neocortex (Shadow Mode)
This launches the Neocortex domain as a standalone sidecar. It will start ingesting logs and training the Brain.
```bash
python apps/reference/domains/neocortex/main.py
```
*   **Expected Output:** `NEOCORTEX DOMAIN - PHASE 6 (UNIFIED WAL TAILING)`
*   **Stop:** `Ctrl+C` (Triggers graceful shutdown and checkpoint saving).

### 2.3. Resetting Memory (Cold Start)
If the VAE latent space becomes corrupted or you change model architecture, wipe the state:
```bash
rm -rf apps/reference/domains/neocortex/data/checkpoints/*
rm apps/reference/domains/neocortex/data/tailer_state.json
```

## 3. Monitoring & Alerts

### 3.1. Log Streams
Monitor these files (`tail -f`):
*   `logs/neocortex.log`: General system health, ingestion stats.
*   `logs/aurora_core.log`: Trading activity (PnL).

### 3.2. Key Metrics (Health Check)
Look for these patterns in the logs:
1.  **Ingestion Rate:** `Progress: Features=... Orders=...` (Should increase steadily).
2.  **VAE Loss:** `Training step X: VAE=...` (Should decrease and stabilize < 50.0).
3.  **Heartbeat:** If no logs appear for > 1 minute, the `BrainBridge` might be hung.

### 3.3. Critical Alerts
The system emits `EVT:NEOCORTEX_ALERT` for:
*   **OOD (Out of Distribution):** Feature vector variance > threshold.
*   **Data Lag:** Order timestamp < Feature timestamp (Causality violation).
*   **Checkpoint Fail:** Unable to write to disk.

This documentation suite establishes **Neocortex** as a pioneering **Latent-Life Agent** architecture for algorithmic trading. By decoupling perception from action and enforcing strict causal learning, we avoid the pitfalls of traditional "black box" AI.

The system is currently in **Phase R0 (Observer)**. It has a robust body, senses, and memory. The path forward involves closing the reward loop (R1) and enabling active reasoning (R2). The foundation laid here is mathematically rigorous, technically resilient, and ready for evolution.
