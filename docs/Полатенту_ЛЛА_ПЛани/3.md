# IMPLEMENTATION ROADMAP & FUTURE LOGIC (TO BE)
**Strategic Vision:** Transform Neocortex from a Passive Observer (R0) into an Active Causal Agent (R3).

## 1. Remaining Modules & Features

To achieve fully autonomous, risk-aware trading, the following components must be engineered:

1.  **Reward Extraction Engine:** A robust parser or direct integration to fetch realized PnL per trade. Without this, RL is impossible.
2.  **Causal Graph (Hippocampus):** A vector database or graph structure that clusters latent states ($z$) and maps probabilistic transitions ($z_t \xrightarrow{a} z_{t+1}$). This is the system's "Wisdom".
3.  **The Dreamer (Offline Consolidator):** An offline process that utilizes the World Model to perform counterfactual rollouts ("What if I held instead of sold?") to densify the Causal Graph.
4.  **Geometric Schrödinger Bridge (GSB):** A replacement for simple RNN predictions with stochastic trajectory generation that respects market geometry (risk barriers).
5.  **Modulation Interface (Actuation):** A safe, API-driven way for Neocortex to influence Aurora's parameters (e.g., risk limits) without hard-coding config files.

## 2. Phased Implementation Plan

We adhere to the **"Crawl, Walk, Run"** philosophy. We do not enable actuation until perception is perfect.

### PHASE R1: The Learner (Fixing the Feedback Loop)
**Goal:** Close the Reinforcement Learning loop. The agent must feel "pain" (Loss) and "pleasure" (Profit).

*   **Logic:** Currently, the agent is blind to outcomes. We must connect the VAE's "eyes" to the PPO's "wallet". We cannot optimize a policy without a valid Reward Signal.

*   **Tasks:**
    1.  **Implement `PnLParser`:** Develop a regex-heavy (or DB-connected) parser for `aurora_core.log` to extract exact PnL values ($) for every `POSITION_CLOSED` event.
    2.  **Enhance `Episode` Schema:** Add fields: `realized_pnl`, `max_drawdown`, `holding_time`.
    3.  **Value Function Pre-training:** Train the Critic network ($V(z)$) to predict future PnL based on the latent state $z$.
    4.  **Student-t Decoder Upgrade:** Modify VAE Decoder to output $(\mu, \sigma, \nu)$ to implicitly learn tail risks (fat tails) from feature distributions.

*   **Definition of Done:**
    *   Logs show `Episode Complete: Reward=$+15.0` (not 0.0).
    *   The PPO Critic Loss begins to converge (the agent can predict if a state is profitable).
    *   VAE Decoder accurately models fat tails ($\nu$ parameter converges).

### PHASE R1.5: The Dreamer (Offline Consolidation)
**Goal:** Build the Causal Graph to enable "Intuition" and counterfactual learning.

*   **Logic:** Online learning is dangerous and slow. "Dreaming" allows the agent to replay past experiences, mix them, and learn from "what didn't happen" (counterfactuals) without risking capital.

*   **Tasks:**
    1.  **Implement `CausalGraph`:** A persistence layer (SQLite + Vector Index) storing clusters of $z$.
    2.  **Implement `Dreamer` Worker:** A background process that:
        *   Takes completed episodes.
        *   Uses the World Model to simulate alternative actions.
        *   Updates transition probabilities in the Graph.
    3.  **Experience Replay:** Feed synthetic "dream" batches into the PPO training loop to boost sample efficiency.

*   **Definition of Done:**
    *   Graph contains >1000 nodes (market regimes).
    *   Querying the graph "What happens if I Buy in State $Z_{crash}$?" returns "High probability of Loss".

### PHASE R2: The Advisor (Shadow Actuation)
**Goal:** Validate the Agent's decision-making quality against the Legacy System (Aurora) in real-time.

*   **Logic:** Before giving the agent money, we must verify its "Shadow Intents". Does it signal SHORT before a crash? Does it signal EXIT before a reversal? We need statistical proof of Alpha.

*   **Tasks:**
    1.  **Unlock PPO Actor:** Enable the Actor network to output discrete actions (Long/Short/Flat) based on $z$.
    2.  **Divergence Engine:** A real-time analytics module that compares `Aurora.Action` vs `Neocortex.ShadowIntent`.
    3.  **Risk Gating (CVaR):** Implement `RiskGate` that blocks any Shadow Intent if the World Model predicts a CVaR (95%) < Threshold.
    4.  **Geometric SBP (Prototype):** Replace simple rollouts with Brownian Bridges to estimate path risks more accurately.

*   **Definition of Done:**
    *   **Shadow PnL > 0:** The cumulative theoretical PnL of Shadow Intents exceeds a baseline (Buy & Hold).
    *   **Sharpe Ratio > 1.5:** On the Shadow Equity curve.
    *   **Safety Check:** CVaR Gate correctly blocks high-risk trades in simulated crash scenarios.

### PHASE R3: The Agent (Controlled Actuation)
**Goal:** Grant Neocortex limited control over the trading process via the Modulation Interface.

*   **Logic:** We never give "Full Control". We give **Influence**. Neocortex should act as a "Risk Officer", tightening limits during instability, or a "Sniper", signaling entry when confidence is maximal.

*   **Tasks:**
    1.  **Implement `ModulationInterface`:** An API allowing Neocortex to issue `CMD:MODULATE_RISK` (e.g., "Reduce Max Position Size by 50%").
    2.  **Implement `SignalBridge`:** Allow Neocortex to inject `TRADE_INTENT` directly into Aurora's Execution Engine (gated by a hard Allow-List).
    3.  **Kill-Switch Integration:** If Neocortex's internal metrics (Viability) degrade, it must auto-disconnect from the Execution Engine.

*   **Definition of Done:**
    *   Live automated trading with positive PnL.
    *   Zero critical incidents (no "fat finger" orders).
    *   System passes "Chaos Monkey" tests (resilience to data lag/disconnects).

## 3. Dependencies & Critical Path

The roadmap assumes a strict dependency chain. **Skipping steps is fatal.**

| Dependency Block | Blocks Phase | Reason |
| :--- | :--- | :--- |
| **Reward Parsing** | R1 | You cannot train a Critic (Value Function) without a Reward signal. |
| **VAE Stability** | R1.5 | You cannot build a Causal Graph if the coordinate system ($z$) keeps shifting (drifting). |
| **World Model Accuracy** | R2 | You cannot trust Shadow Intents if the model's prediction of the future is random. |
| **Shadow Alpha** | R3 | You cannot enable Actuation if the Shadow PnL is negative. |

### Immediate Blocker:
The **Reward Extraction** (Phase R1, Task 1) is the single most critical blocker right now. Until `pnl != 0.0`, the system is brain-dead in terms of Reinforcement Learning.
