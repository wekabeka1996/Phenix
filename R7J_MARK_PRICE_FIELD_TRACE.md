# R7J Mark Price Field Trace

1. MarketDataProxy builds a market tick payload with price, bid, ask, mid, and related fields, then emits EVT:MARKET_TICK_RECEIVED from [apps/reference/domains/market_data/proxy.py](apps/reference/domains/market_data/proxy.py#L250).
2. PositionTracking.__init__() reads enable_market_tick_subscription; because the active config is false, the listener is not attached in [apps/reference/domains/position_tracking/position_tracking.py](apps/reference/domains/position_tracking/position_tracking.py#L132) and [config/aurora/domains.yaml](config/aurora/domains.yaml#L392).
3. If the listener were active, on_market_tick() would accept mid or price and call update_mark_price() with the current timestamp in [apps/reference/domains/position_tracking/position_tracking.py](apps/reference/domains/position_tracking/position_tracking.py#L260) and [apps/reference/domains/position_tracking/position_tracking.py](apps/reference/domains/position_tracking/position_tracking.py#L1093).
4. update_mark_price() writes the cached value into _mark_prices[symbol]; _fresh_mark_price() later checks that cache for freshness before it is consumed in snapshots in [apps/reference/domains/position_tracking/position_tracking.py](apps/reference/domains/position_tracking/position_tracking.py#L1093) and [apps/reference/domains/position_tracking/position_tracking.py](apps/reference/domains/position_tracking/position_tracking.py#L1066).
5. _get_positions_snapshot() uses the cached mark price first, then emits markPrice as null when no fresh value exists in [apps/reference/domains/position_tracking/position_tracking.py](apps/reference/domains/position_tracking/position_tracking.py#L1371).
6. The captured runtime trace for XRPUSDT shows position_snapshot.mark_price as null and peak_giveback_snapshot.mark_price as null while the position is open in [logs/trade_lifecycle.jsonl](logs/trade_lifecycle.jsonl#L17641).
7. The account-update contract allows markPrice and derived unrealized values to remain null when the source payload does not provide them in [apps/reference/domains/position_tracking/docs/EVENT_CONTRACTS.md](apps/reference/domains/position_tracking/docs/EVENT_CONTRACTS.md).
